# Planned Updates

This page describes direction, not a dated roadmap. Priorities can change as the framework is tested in
real projects.

## Near-term focus

- expand the tutorial path with real Unity screenshots and short, reproducible recipes;
- strengthen the Compact Multiplayer Showcase as the reference integration project;
- add focused tests around authority, rollback, generated network models, inventory, and equipment;
- improve validation messages for incomplete runners, scenes, network prefabs, and content tables;
- document common extension points for project-specific game modes, actors, subsystems, and UI.

## Later exploration

- more sample gameplay patterns built from the existing modules;
- better authoring and inspection for network models and replicated collections;
- profiling guidance for content loading, network state, and presentation pools;
- upgrade notes and migration checks as public APIs settle;
- clearer compatibility matrices for supported Unity, Fusion, and package dependency versions.

## How to read this list

Items are intentionally not assigned to versions or dates until they are scheduled. A change is shipped
only when it appears in the package changelog and release notice; this page alone should not be used as
a delivery commitment.
