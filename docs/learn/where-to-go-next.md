After completing one or two [Recipes](recipes/index.md), consult the Manual section that corresponds
to your next implementation goal.

| Goal | Continue with |

| Host, connect, travel, or stream a level | [Manual: GameInstance & Travel](../manual/game-instance-travel.md) |
| Add controls or modal input contexts | [Manual: Input](../manual/input.md) |
| Create actions, costs, cooldowns, or cancellation | [Manual: Abilities](../manual/abilities.md) |
| Add health, formulas, buffs, or periodic damage | [Manual: Attributes & Effects](../manual/attributes-effects.md) |
| Add items and layouts | [Manual: Inventory](../manual/inventory.md) |
| Equip an item and grant abilities | [Manual: Equipment](../manual/equipment.md) |
| Add doors, pickups, or prompts | [Manual: Interaction](../manual/interaction.md) |
| Tune locomotion and moving platforms | [Manual: Character Controller](../manual/character-controller.md) |
| Add ranged, melee, or throwable combat | [Manual: Weapon](../manual/weapon.md) |
| Add particles, audio, or camera response | [Manual: Feedback](../manual/feedback.md) |
| Build screens, windows, loading UI, or markers | [Manual: UI](../manual/ui.md) |
| Load Addressables content | [Manual: Assets](../manual/assets.md) |
