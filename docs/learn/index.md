# Learn RedEngine

This sequence introduces RedEngine through a working Unity project and a small multiplayer game,
then directs you to the relevant system guides.

## The learning path

1. [Meet RedEngine](introduction.md) — learn the framework's application, world, actor, and input model.
2. [Install RedEngine](installing.md) — import the package and verify the required project setup.
3. [Getting Started](getting-started.md) — configure Fusion and run the showcase with two peers.
4. [Framework Overview](framework-overview.md) — see where each kind of code belongs.
5. [First Multiplayer Game](first-multiplayer-game.md) — assemble a game mode, player, input, and one
   replicated gameplay loop.
6. [First Multiplayer Scene](first-multiplayer-scene.md) — follow the longer inspector-by-inspector setup.
7. [Recipes](recipes/index.md) — add one ability, effect, item, UI flow, marker, or streamed level at a
   time.
8. [Where to Go Next](where-to-go-next.md) — choose the next system based on what you want to build.

Follow these pages in order when setting up a new project. For an existing RedEngine project,
consult the [Manual](../manual/index.md) directly.
